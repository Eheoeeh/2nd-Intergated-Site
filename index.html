Aura Console References

Control the entire experience using console commands:

  • help - Show this command helper list.
  • hue <0-360> - Change the OKLCH theme hue dynamically.
  • clear - Wipe terminal logs.
  • wave <freq> <amp> - Modify Wave oscillator parameters.
  • status - Output core system configuration states.
